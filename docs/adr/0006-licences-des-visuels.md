# Visuels : Kenney CC0, rien de dessiné à la main, domaine public, ODbL

Le porteur ne dessine rien. Les règles tiennent même le jour où une association ou des dons existeront (l'exception de panorama, valable pour un particulier sans usage commercial, ne suffirait plus) :

- **Assets tiers : CC0 uniquement.** Décor et personnages modulaires Kenney (CC0). Pas de CC BY-SA ni de GPL (ex. Liberated Pixel Cup, OpenMoji), même populaires, pour ne pas mélanger les licences.
- **Tout le reste est généré par script dans la palette Kenney** : variantes d'apparence (teint, cheveux, vêtements) par changement de palette, accessoires inclusifs (fauteuil roulant, poussette, canne). Le style reste cohérent sans dessinateur.
- **Pas de pictos sur les pancartes** en V1 : couleur + forme + slogan.
- **Monuments : hors V1.** La place d'arrivée est une place générique du tileset, avec son nom affiché. Plus tard, uniquement des monuments du **domaine public** (auteur mort depuis plus de 70 ans) ; l'architecture récente reste un bâtiment générique (ex. à Bastille, la colonne de Juillet oui, l'Opéra non).
- **Tilemaps dérivées d'OSM : ODbL**, publiées dans le dépôt, avec la mention « © les contributeurs d'OpenStreetMap » visible en jeu. Une tilemap envoyée au client est une base de données dérivée, pas une simple image rendue. Le code garde sa propre licence.
- Pas de commerces, d'enseignes ni de logos dans le décor.
