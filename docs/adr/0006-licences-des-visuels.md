# Licences des visuels : CC0, domaine public, ODbL

Les règles tiennent même le jour où une association ou des dons existeront (l'exception de panorama, valable pour un particulier sans usage commercial, ne suffirait plus) :

- **Tileset et assets tiers : CC0 uniquement.** Pas de CC BY-SA ni de GPL (ex. Liberated Pixel Cup), même populaires, pour ne pas mélanger les licences. Le tileset est choisi avant tout dessin, et avatars et monuments s'alignent sur son style.
- **Monuments : domaine public uniquement** (auteur mort depuis plus de 70 ans). L'architecture récente devient un bâtiment générique (ex. à Bastille, la colonne de Juillet oui, l'Opéra non).
- **Tilemaps dérivées d'OSM : ODbL**, publiées dans le dépôt, avec la mention « © les contributeurs d'OpenStreetMap » visible en jeu. Une tilemap envoyée au client est une base de données dérivée, pas une simple image rendue. Le code garde sa propre licence.
- Pas de commerces, d'enseignes ni de logos dans le décor.
